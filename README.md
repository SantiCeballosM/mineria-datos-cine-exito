# Proyecto de Minería de Datos — Cine Éxito

## Problema

¿Qué características de las películas están en relación con un éxito en taquilla para apoyar la hipótesis de que películas podrían tener mayor demanda en un cine?

## Tema

Análisis y predicción del éxito de películas mediante técnicas de minería de datos.

## Objetivo

Proporcionar información a los administradores o encargados de programación del cine para la identificación de características las cuales se asocian con películas de mayor demanda al utilizar datos históricos.

- IMDb Datasets

## Alcance

Se analizará la información histórica de cada película, donde se incluya el género, fecha de estreno, duración, calificación, popularidad, número de votos y datos de la taquilla cuando estén disponibles. Se busca identificar patrones y relaciones de variables y el éxito de las películas en el público. Se hace un análisis descriptivo y si la cantidad y calidad de estos permiten realizar una etapa predictiva para la clasificación o  estimación del éxito.

NO cubre: Venta de entradas, pagos, inventario, plataformas de streaming, información personal de los clientes, administración de salas y del cine.
